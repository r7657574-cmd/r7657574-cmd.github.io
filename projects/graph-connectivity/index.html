Multi-Agent Large Language Models for Connectivity Restoration in Damaged Graphs

Intent-aware repair begins with the graph itself: damaged components, spatial costs, forbidden edges, and required connections become a shared structural record. Natural-language preferences are then converted into explicit objectives, candidate edit plans are compared on graph copies, and the selected repair is checked against the original constraints.

Core contribution

Structure

Make the graph the common language

The decision state is expressed through components, positions, path structure, forbidden edges, and required connections. Semantic interpretation is useful only when it resolves into these checkable graph objects.

Intent

Turn preferences into explicit optimization signals

Requests for low cost, low latency, reliable connectivity, or redundancy become visible priorities. This makes the trade-off behind a selected strategy inspectable instead of hiding it inside prose.

Repair

Select a graph edit plan, not arbitrary code

Bridge, component-tree, and latency operators share one interface. New behavior can be formed by bounded composition of those operators, then evaluated and verified under the same constraints.

Proposal layer

Interpret and suggest

A language model or person may propose intent weights or a strategy composition, but the proposal is reduced to typed values and known graph operators.

Graph core

Execute and verify

The public core never imports generated modules. It edits a graph copy, rejects infeasible plans, and checks connectivity, forbidden-edge violations, and required connections after repair.

Project summary

Connectivity restoration is treated as a constrained decision over the damaged graph rather than as unconstrained code generation. The workflow first grounds natural-language intent in graph-level priorities such as connectivity, construction cost, and path efficiency. It then extracts the topology and hard edge constraints, compares minimum-spanning-tree, bridge, and latency-oriented repair plans, and validates the selected edits on the resulting graph. This formulation keeps the strategy space explicit while allowing the decision process to adapt to heterogeneous damage patterns and user objectives. Evaluation on synthetic and real-world networks studies intent alignment, zero-shot repair behavior, and the complementary value of semantic grounding and structural validation relative to heuristic and reinforcement-learning baselines.

Release boundary

Manuscript and logical core.

The public snapshot deliberately omits provider integration, private prompts, datasets, reinforcement-learning code, generated files, raw traces, and the full experimental harness.
