What the core enforces

  1. Theory-instance validity: sources, premises, structural objects, and falsifiers must be explicit.
  2. Finite computational grounding: the theory must produce a solver-facing object and an identifying verifier.
  3. Measured headroom: a learned component is considered only when a real unresolved computation remains.
  4. Matched evidence: neural and hybrid routes need a matched comparator and a no-learning shadow.
  5. Fresh transfer checks: out-of-distribution or scale evidence is required before final validation.
  6. Immutable negative results: a failed frozen candidate becomes evidence; revisions start a new lineage.

Abstract

Partial differential equations (PDEs) underpin models of transport, diffusion, fluids, elasticity, and many other physical systems, while AI4PDE increasingly seeks reusable learned solvers for parameterized PDE families. Most neural PDE pipelines, however, select a representation or architecture before asking whether mathematical theory can restructure the computation. We introduce Theory2Method, a multi-agent system in which every task starts from the same frozen, task-independent taxonomy of broad theory categories and the same original-source search environment. A Theory Search Agent formulates queries, retrieves source passages, and selects results by premise match and computational relevance; a Method Design Agent grounds the selected result into solver-relevant structure, validity conditions, and a typed unresolved computation. A deterministic type-aware selector then chooses a numerical or learned route, and coupled validators assess theory-instance validity and method effectiveness. The resulting portfolio includes exact numerical transformations, structure-guided learned methods, and rejection of an inadmissible stochastic proposal. Across the retained learned routes, the methods improve their prespecified matched comparators while satisfying the corresponding theory-derived checks. These results show how source-grounded agent reasoning can determine the representation, prediction target, and allocation between analysis and learning before model training.
