Theory2Method

Auditable Multi-Agent Reasoning for Theory-First PDE Solver Design. The workflow searches mathematical theory before choosing a solver, turns an applicable result into solver-relevant structure, and lets the computation left unresolved determine how the method should be built.

Type the remaining computation explicitly. Its form determines whether the implementation should be numerical, learned, hybrid, narrowed, or rejected.

What changes before training

  1. Representation: theory may transform the state, basis, coordinates, or domain in which the problem is solved.
  2. Prediction target: learning is assigned only to the relation that theory does not already determine.
  3. Computational allocation: exact analysis, numerical computation, and learning receive distinct responsibilities.
  4. Validity criteria: mathematical applicability and empirical performance are tested separately, so one cannot mask failure in the other.

Abstract

Partial differential equations (PDEs) underpin models of transport, diffusion, fluids, elasticity, and many other physical systems, while AI4PDE increasingly seeks reusable learned solvers for parameterized PDE families. Most neural PDE pipelines, however, select a representation or model architecture before determining whether mathematical theory can fundamentally restructure the computational problem. We introduce Theory2Method, a multi-agent system that uses mathematical theory upstream of solver selection. All tasks start from the same task-independent taxonomy of broad mathematical theory categories and a common original-source search environment. A Theory Search Agent retrieves candidate mathematical results and selects theories whose assumptions match the target PDE and whose conclusions have plausible computational relevance. A Method Design Agent then grounds the selected theory into solver-relevant computational structure, applicability conditions, and a typed unresolved computation. A deterministic type-aware selector uses this unresolved computation to choose a numerical or learned implementation route, while coupled validators assess both theory-instance validity and method effectiveness. Across a diverse PDE portfolio, the resulting methods include exact numerical transformations, structure-guided learned solvers, and rejection of mathematically inadmissible proposals. The retained learned methods improve their prespecified matched comparators while satisfying the corresponding theory-derived validity conditions. These results demonstrate a practical role for large language model agents in AI4PDE beyond architecture or hyperparameter search: using mathematical theory to determine the representation, prediction target, and computational allocation before model training.
