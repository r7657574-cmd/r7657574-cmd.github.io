# 文学与感知

[项目主页](https://r7657574-cmd.github.io/projects/literary-perception/) · [使用指南](https://r7657574-cmd.github.io/projects/literary-perception/usage.html) · [平台说明](https://r7657574-cmd.github.io/projects/literary-perception/platform.html#access) · [公开阅读反馈](https://r7657574-cmd.github.io/projects/literary-perception/platform.html#feedback)

研究中文文学创作中的人物感知、情绪、语言组织与持续阅读。公开内容包含三段研究介绍、五个可变文学目标和原创开篇作品。完整创作流程及内部代理材料保持私有。

当前公开功能为作品阅读、使用说明与 GitHub 阅读反馈。反馈表单打开 Issue 草稿，用户检查后自行提交；公众在线生成尚未开放。已经取得私有程序的使用者可以按照本机步骤创作。

“0 特定提示、0 特定参考文章”指使用者无需编写专门提示或指定模仿作品；系统内部仍有创作说明、研究材料与审核要求。作品为 AI 辅助创作，经过编辑审读；文学效果需要实际阅读判断。

## 公开作品

- [《炉下有河》十章全文](samples/under-furnace.txt)：工业玄幻与悬疑对抗，保留已有公开样例。
- [《万山夜行》十章全文](samples/night-mountains.txt)：山神、影术与兄妹救援，2026年10月4日持续感知修订稿，正文29,621汉字。分章文本在 `samples/night-mountains/`。

《万山夜行》的具身与感知材料覆盖十章中的24个场景。写作者在修订前完整读取49份个人视图，在18个场景修改文字，在6个场景保留原文，另有第四章进食与借刀的一次返查。身体余效、环境变化、各人所知与本人经验参与创作；心理、语气和句群由写作者组织。当前规则模拟与文本 embedding 不证明全文逐句经过模拟，也不直接判定文学效果。
