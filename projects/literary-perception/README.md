# 文学与感知

[项目主页](https://r7657574-cmd.github.io/projects/literary-perception/) · [使用指南](https://r7657574-cmd.github.io/projects/literary-perception/usage.html) · [平台说明](https://r7657574-cmd.github.io/projects/literary-perception/platform.html) · [十章全文](samples/under-furnace.txt)

研究中文文学创作中的人物感知、情绪、语言组织与持续阅读。公开内容包含三段研究介绍、五个可变文学目标和原创开篇作品。完整创作流程及内部代理材料保持私有。

“0 特定提示、0 特定参考文章”指使用者无需编写专门提示或指定模仿作品；系统内部仍有创作说明、研究材料与审核要求。作品为 AI 辅助创作，经过编辑审读；文学效果需要实际阅读判断。
