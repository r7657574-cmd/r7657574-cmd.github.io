项目主页使用指南阅读反馈

阅读、创作与反馈

当前可公开阅读两部十章开篇并提交阅读反馈。公众在线生成尚未开放；完整写作流程保存在私有项目中。

从公开网址进入创作

公众服务拟提供这样的使用方式：登录自己的 ChatGPT 账户，授权使用自己的套餐，填写题材、目标和篇幅，等待创作完成，再阅读、复制或下载文章。用户无需填写 API key。网站登录与使用 ChatGPT 套餐是分别授权的能力。

远程托管应用使用 ChatGPT 套餐需要获得 OpenAI 的接入资格，见官方套餐授权说明与网站登录说明。本项目尚未取得该资格或部署多用户生成服务，所以目前没有可用的公众登录生成按钮。

现有 GitHub Pages 已提供公开网址，可以继续用于阅读、介绍和反馈。自有域名可让网址更易记；生成服务另需 HTTPS 后端、每位用户的账户授权、作品访问权限和作业管理。注册域名不会自动提供这些功能。

已取得私有程序的本机使用者

  1. 安装官方 Codex CLI，并通过官方页面登录自己的 ChatGPT 账户。
  2. 在私有项目的 projects/literary-perception-lab 目录安装依赖：python -m pip install -e '.[platform]'。
  3. 执行 python platform/run_server.py，在自己的浏览器打开 http://127.0.0.1:8765。
  4. 刷新账户状态，选择账户实际可用的 GPT-6.1-sol，填写创作要求与篇幅，确认服务处理同意后生成。
  5. 完成后阅读、复制或下载正文；作品下方“阅读意见”保存在该电脑中。

127.0.0.1 始终指向访问者自己的电脑。仅浏览本网站不会获得或启动私有程序。本机每次创作100至5000汉字，研究阅读授权默认关闭；本机反馈不会自动传给项目作者。

作品交付范围

对外服务的设计范围是用户自己的最终文章、作业状态、下载文件及反馈回执。准备材料、候选、模拟结果和审稿记录由服务器内部保存，不向浏览器提供读取接口；每份作品需要检查用户归属。

完整程序运行在使用者电脑上时，电脑拥有者可以检查文件和运行过程。为了减少中间资料曝光，公众创作需要将私有流程放在受控服务器上。模型服务仍会接收必要提示与材料，内部提示的绝对保密尚未得到验证。

项目作者私有阅读作品及用作品改进流程，需要用户单独同意；模型训练和公开作品分别授权。用户自己填写的反馈与授权不会由公开主页自动收集。
